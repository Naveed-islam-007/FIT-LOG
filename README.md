# FitLog — Workout Library

A dark, no-nonsense gym companion built with Next.js. Browse a library of workouts, lock lifts into today's plan, save others for later, and track your session's exercises, minutes, and calories as you go.

## Technologies Used

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React Toastify** — toast notifications
- **React Context API** — global state for Today's Plan and Saved workouts

## Key Features

1. **Workout Library** — Browse 12 workouts in a responsive 3x4 grid, each showing category tags, equipment, duration, calories, and rating.
2. **Detailed Workout Pages** — Full breakdown per lift: specs (equipment, difficulty, sets, reps), step-by-step instructions, and quick actions to add it to your plan or save it for later.
3. **Live Plan Tracking** — A capped, 5-lift Today's Plan with real-time metrics (exercises, minutes, calories) that update instantly as workouts are added or removed.
4. **Today's Plan / Saved Tabs** — Manage active and saved workouts separately, with the ability to mark lifts done or remove them, complete with toast feedback on every action.
5. **Sort & Filter** — Re-sort the library by Duration, Calories, or Rating on the fly, without losing your place.
